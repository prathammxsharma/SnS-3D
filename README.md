# Shoot N Survive — Cinematic Forest Slice

A separate, playable visual-direction test. It does not overwrite or replace the existing Shoot N Survive source.

## Run
Open `index.html` in a modern browser. No build step or dependencies are required.

## Controls
- A / D or Left / Right: move
- Space / Up: jump
- Touch controls are available on narrow screens

## Scope
- Side-scrolling camera
- Layered forest depth and parallax
- Atmospheric lighting and fog
- Character movement, jumping, gravity and ground collision

This is a visual and movement proof of concept, not a finished game.
